# Résumé prototype icon attribution

The résumé sprite in `_includes/career-icons.html` contains unmodified path geometry from these official source projects. SVG wrappers are converted to local symbols; artwork inherits the site's text color and always accompanies a visible text label.

- Simple Icons: https://github.com/simple-icons/simple-icons — CC0-1.0 project license; individual brand trademarks belong to their owners. Source files on the `develop` branch under `icons/`: `airbnb.svg`, `atlassian.svg`, `python.svg`, `confluence.svg`, `jira.svg`, `bitbucket.svg`, `swagger.svg`.
- Bootstrap Icons: https://github.com/twbs/icons — MIT license, copyright 2019–2026 The Bootstrap Authors. Source files on the `main` branch under `icons/`: `buildings.svg`, `people.svg`, `tools.svg`, `funnel.svg`, `link-45deg.svg`, `briefcase.svg`.

Retrieved October 2, 2026. The badge treatments are custom, scoped résumé styles using the existing V2 canyon palette; Bootstrap button groups are reused for the view controls.
